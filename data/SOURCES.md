# مصادر البيانات

- **القرآن الكريم بالرسم العثماني:** Quran JSON / Tanzil. المصدر: https://quran-json.risanb.com/text/uthmani/quran.json و https://tanzil.net/ . يجب الحفاظ على النص كما هو ونسبته إلى المصدر، ومراجعة شروط الترخيص الحالية قبل إعادة التوزيع.
- **حصن المسلم:** https://github.com/rn0x/hisn_almuslim_json . تُنزّل البيانات من المستودع الأصلي عند تشغيل `npm run prepare:data`.
- **التلاوات:** روابط مباشرة من EveryAyah؛ يلزم اتصال بالإنترنت، وحقوق التسجيلات تعود لأصحابها: https://everyayah.com/

البيانات تُنزّل إلى مجلد `data/` قبل التشغيل أو البناء. راجع شروط المصادر قبل النشر التجاري.
