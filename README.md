# نور الإسلام | Noor Islam

تطبيق إسلامي عربي باستخدام Expo وReact Native. يضم القرآن الكريم بالرسم العثماني، حصن المسلم، التلاوات، المسبحة الإلكترونية، وصفحة لتحديد الموقع للمساعدة في ميزات القبلة.

## بدء التشغيل

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run prepare:data
npx expo start
```

يجلب الأمر `npm run prepare:data` ملفات البيانات من مصادرها العامة إلى `data/quran-uthmani.json` و`data/hisn-muslim.json`. يجب الاتصال بالإنترنت لأول تنزيل.

## بناء APK عبر GitHub Actions

1. افتح تبويب **Actions** في هذا المستودع.
2. اختر **Build Android APK** ثم **Run workflow**، أو ادفع تغييراً إلى فرع `main`.
3. بعد نجاح التشغيل افتح النتيجة وابحث عن **Artifacts**.
4. نزّل `noor-islam-android-apk`.

ملف APK الناتج نسخة Release غير موقعة بمفتاح نشر خاص؛ للاختبار فقط. لا تضع مفاتيح التوقيع أو الأسرار داخل المستودع.

## البناء محلياً

```bash
npm run build:android
```

## محتوى التطبيق ومصادره

- القرآن بالرسم العثماني: Quran JSON / Tanzil — راجع `data/SOURCES.md` وشروط المصدر.
- الأذكار: مستودع حصن المسلم المشار إليه في `data/SOURCES.md`.
- التلاوات الصوتية: EveryAyah؛ التشغيل يحتاج إنترنت وتظل حقوق التسجيلات لأصحابها.
