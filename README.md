# نور الإسلام | Noor Islam 🕌

تطبيق إسلامي باللغة العربية، مبني باستخدام **Expo وReact Native**، يجمع أدوات يومية للقرآن الكريم والذكر والصلاة في واجهة واحدة. صُمّم ليتيح الوصول إلى المحتوى الأساسي دون الحاجة إلى اتصال دائم بالإنترنت، مع توضيح الميزات التي تحتاج اتصالًا أو أذونات من الجهاز.

## ✨ مميزات التطبيق

### 📖 القرآن الكريم
- عرض سور القرآن الكريم بالنص العثماني.
- تصفّح السور والآيات من داخل التطبيق.
- حفظ موضع القراءة والرجوع إليه لاحقًا.
- إضافة الآيات إلى العلامات المرجعية وإدارتها.
- تنزيل تلاوة السورة للاستماع إليها دون اتصال، بعد اكتمال التنزيل.

### 🤲 حصن المسلم والأذكار والأدعية
- الوصول إلى محتوى حصن المسلم المضمّن بعد تجهيز بيانات التطبيق.
- أذكار الصباح والمساء ومجموعات من الأدعية اليومية.
- أدعية عامة وأذكار قبل النوم وعند الكرب.
- المسبحة الإلكترونية للمساعدة على التسبيح والعدّ.

### 🕌 مواقيت الصلاة
- حساب محلي لمواقيت الفجر والظهر والعصر والمغرب والعشاء باستخدام مكتبة `adhan` وطريقة الحساب المصرية.
- استخدام موقع الجهاز لحساب المواقيت المناسبة للموقع الحالي.
- حفظ آخر إحداثيات معروفة للمساعدة على استخدام المواقيت لاحقًا دون إنترنت.
- إمكانية جدولة تنبيهات الصلاة على الجهاز. يتطلب ذلك منح أذونات الإشعارات، وقد تحتاج التنبيهات إلى إعادة جدولة دورية بحسب نظام التشغيل وإعدادات الجهاز.

> **تنبيه:** قد تختلف المواقيت المعروضة عن الجداول الرسمية المحلية بسبب طريقة الحساب أو إعدادات الموقع. يُرجى مراجعتها مع جهة موثوقة في منطقتك، خصوصًا لمواقيت الفجر والعشاء.

### 🧭 اتجاه القبلة
- حساب اتجاه القبلة اعتمادًا على الإحداثيات الجغرافية.
- استخدام اتجاه الجهاز/البوصلة عند توافر المستشعرات والأذونات اللازمة.
- قد تتأثر قراءة البوصلة بالتداخل المغناطيسي، لذا حرّك الجهاز أو عاير البوصلة عند الحاجة.

### 🎧 القرّاء والتلاوات
- اختيار القارئ والسورة وتشغيل التلاوة آيةً بعد آية.
- دعم استمرار التشغيل في الخلفية بحسب إعدادات الجهاز ونظام التشغيل.
- البث المباشر من EveryAyah يحتاج إلى الإنترنت.
- يمكن تنزيل السور من قسم المزايا الإضافية للاستماع إليها دون اتصال.

### 🌙 مزايا إضافية وتجربة الاستخدام
- حفظ العلامات المرجعية وموضع القراءة والإعدادات محليًا على الجهاز.
- خيار المظهر الداكن.
- عرض التاريخ الهجري إذا كان مدعومًا من بيئة الجهاز.
- واجهة عربية باتجاه من اليمين إلى اليسار.

## 📶 ما الذي يعمل دون إنترنت؟

**يمكن استخدامه دون اتصال بعد تجهيز بيانات التطبيق:** نص القرآن المضمّن، بيانات حصن المسلم التي تم تنزيلها أثناء التجهيز، المسبحة، الأدعية المحلية، الحساب المحلي لمواقيت الصلاة بعد توفر الإحداثيات، والتلاوات التي تم تنزيلها بالكامل.

**قد يحتاج إلى الإنترنت:** تنزيل بيانات التطبيق لأول مرة، تشغيل التلاوات المباشرة، وتنزيل ملفات صوتية جديدة. ويحتاج تحديد الموقع لأول مرة إلى أذونات الجهاز، وقد يتطلب الحصول على إحداثيات جديدة خدمات الموقع.

## 🛠️ المتطلبات والتشغيل محليًا

- Node.js 20 أو أحدث.
- npm.
- للإنشاء الأصلي لأندرويد: بيئة Android/Java التي يحتاج إليها Expo وGradle.

ثبّت الاعتماديات وجهّز البيانات ثم شغّل خادم التطوير:

```bash
npm install
npm run prepare:data
npx expo start
```

يقوم `npm run prepare:data` بتنزيل بيانات القرآن وحصن المسلم وملفات الأذان اللازمة للبناء. يتطلب ذلك اتصالًا بالإنترنت. راجع مصادر البيانات والتراخيص قبل إعادة التوزيع.

## 📦 إنشاء APK لأندرويد

### باستخدام GitHub Actions
1. افتح تبويب [Actions](https://github.com/mahamednagyteam-star/noor-islam-/actions).
2. اختر **Build Android APK**.
3. شغّل **Run workflow**، أو ادفع تغييرًا إلى فرع `main` لبدء البناء تلقائيًا.
4. بعد اكتمال التشغيل بنجاح، افتح صفحة التشغيل وابحث عن **Artifacts**.
5. نزّل الأثر باسم `noor-islam-android-apk`.

### البناء محليًا

```bash
npm run build:android
```

ينفّذ الأمر تجهيز البيانات، وإنشاء مشروع Android الأصلي، ثم بناء نسخة Release.

> **مهم:** ملف APK الناتج من سير العمل الحالي مخصص للاختبار ما لم يُوقّع بمفتاح إصدار موثوق. لا تحفظ مفاتيح التوقيع أو كلمات المرور أو الأسرار في المستودع.

## 📚 مصادر البيانات والصوت

- **القرآن الكريم:** Quran JSON / Tanzil. راجع [data/SOURCES.md](data/SOURCES.md) لشروط المصدر.
- **حصن المسلم:** مستودع [rn0x/hisn_almuslim_json](https://github.com/rn0x/hisn_almuslim_json).
- **التلاوات:** [EveryAyah](https://everyayah.com/)؛ حقوق التسجيلات لأصحابها.
- **ملفات الأذان المضمّنة:** مجموعة تسجيلات من [Internet Archive](https://archive.org/details/adhan.recordings.from.doha.qatar). راجع [data/AUDIO-SOURCES.md](data/AUDIO-SOURCES.md) وشروط كل تسجيل قبل إعادة التوزيع.

## 🔐 الخصوصية والأذونات

- يطلب التطبيق إذن الموقع عند الحاجة لحساب المواقيت واتجاه القبلة.
- تُحفظ بعض البيانات مثل الإحداثيات وموضع القراءة والعلامات المرجعية على الجهاز باستخدام التخزين المحلي.
- تتطلب الإشعارات إذنًا من نظام التشغيل، وقد تختلف طريقة عملها باختلاف إصدار Android وإعدادات توفير الطاقة.
- راجع الأذونات التي تمنحها للتطبيق، واختبر السلوك على جهاز فعلي قبل الاعتماد على التنبيهات.

## 🧪 حالة المشروع

المشروع قيد التطوير. وجود ميزة في الكود لا يعني أنها اختُبرت على جميع الأجهزة؛ ينبغي اختبار بناء APK، والتشغيل دون اتصال، وتنبيهات الأذان، والبوصلة، وتشغيل الصوت في الخلفية على جهاز Android فعلي قبل النشر العام.
