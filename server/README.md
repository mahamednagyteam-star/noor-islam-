# خادم مساعد نور الإسلام

هذا الخادم اختياري، ولا يعمل بمجرد إضافة الملف إلى تطبيق الهاتف. يجب نشره على خدمة HTTPS منفصلة ثم توصيل التطبيق بعنوانه.

## المتطلبات
- Node.js 20 أو أحدث.
- بيانات التطبيق داخل `data/quran-uthmani.json` و`data/hisn-muslim.json` (شغّل `npm run prepare:data` قبل تشغيل الخادم).
- مفتاح API محفوظ في بيئة الخادم فقط، وليس داخل تطبيق Android.

## التشغيل
على خادم موثوق:
```sh
npm run prepare:data
OPENAI_API_KEY="ضع-المفتاح-في-متغير-بيئة-آمن" PORT=8787 node server/assistant.mjs
```

يمكن تحديد `OPENAI_MODEL` لاختيار نموذج متاح لحسابك، و`ALLOWED_ORIGIN` لتحديد أصل الويب المسموح بدل القيمة الافتراضية. يوفّر `GET /health` فحصًا بسيطًا و`POST /ask` يستقبل JSON مثل:
```json
{"question":"أين أجد ذكرًا للصباح؟"}
```

يرجع `answer` و`sources` وبيانًا بأن الرد ليس فتوى. يستخدم الخادم استرجاعًا نصيًا بسيطًا من القرآن وحصن المسلم، وقد لا يعثر على كل السياقات ذات الصلة؛ لا تعتمد عليه وحده في مسائل الأحكام.

## متطلبات قبل النشر العام
- أضف مصادقة أو حماية إضافية حسب طبيعة الخدمة، وحدد حدود استخدام وتكلفة مناسبة.
- استخدم HTTPS، واضبط `ALLOWED_ORIGIN` إن كان هناك عميل ويب، وراقب سجلات الخادم دون تخزين أسئلة شخصية غير لازمة.
- راجع شروط خدمة مزود النموذج وسياسة الخصوصية وملاءمة النموذج للغة العربية.
- لا تضع `OPENAI_API_KEY` في تطبيق الهاتف أو مستودع GitHub.
- واجهة الهاتف لا تزال بحاجة إلى ربط عنوان الخادم المنشور قبل استخدام المساعد من داخل التطبيق.
